### BOX ボタン表示位置修正

**問題**: BOX ボタンが ACT ボタンと重なっていた

**原因調査の経緯**
1. `#gm-row` ラッパー方式 → 効果なし（`#game` の `overflow:hidden` が影響か）
2. `position:fixed; bottom:56px` → `position:fixed; top:12px; right:12px` に変更 → まだ重なる
3. Docker キャッシュで古いバイナリが動いていたことが判明
   - `docker compose up --build` はイメージビルド済みキャッシュを使いコンパイルスキップ
   - `cargo run` は起動時に一度だけコンパイルし、その後ファイル変更を検知しない
   - **対策**: `docker exec ... touch src/dungeon.rs && cargo build` → `docker compose restart`
4. `#game` の `overflow:hidden` が `position:fixed` を閉じ込めている → `#game` の外に移動
5. 最終的に `#canvas-wrap` 内に `position:absolute; top:12px; right:12px` で配置
   - `#status-window`（左上）と同じ位置関係、右端に並ぶ

### 宝箱ゲット時のアイテム名フラッシュ表示

**要件**: 宝箱・床ドロップ取得時に「●●をゲット！」と画面に表示する

**実装**
- `dungeon.rs`: `open_chest` の `chest_open` イベントを廃止し `chest_green/red/blue` に変更
  - アイテム種別を直接 JS に伝えられるようになった
- `dungeon.html`:
  - `#item-flash` オーバーレイを追加（画面中央でふわっと浮き上がるアニメーション）
  - `showItemFlash(name, color)` 関数を追加
  - `handleEvent` に `item_green/red/blue` と `chest_green/red/blue` の処理を追加

**デバッグ: フラッシュが表示されない問題**

原因: `ClientMsg::Move` ハンドラが `new_grid_ready`（フロア遷移）のときしか `to_json()` を送らない仕様だった。

```
1. apply_move() → open_chest() → event = "chest_green"
2. to_json() が呼ばれない（通常移動のため）
3. 150ms後にティッカーが tick() を呼ぶ
4. tick() の先頭で self.event = None にリセット ← ここで消える
5. to_json() を送るが event は None
```

修正: Move ハンドラで毎回即座に `to_json()` を送るよう変更。

```rust
// before: フロア遷移時のみ送信
if g.new_grid_ready { ... send to_json ... }

// after: 常に送信（イベントを取りこぼさない）
if g.new_grid_ready { ... send grid_json ... }
if socket.send(Message::Text(g.to_json())).await.is_err() { break; }
```
