## 背景

宇宙トラック野郎と同じスマホ縦画面の操作感を使い、疑似3Dの飛行機レースゲームをプロトタイプとして追加した。
目的は、リアルな3Dポリゴンではなく、Canvas 2D のベクタースキャン風表現で「操作して気持ちいい」飛行感を作ること。

## 実装内容

- トップメニューに `ベクター・エアレース` を追加した。
- `app/src/airrace.html` を新規作成した。
- `docs/airrace.md` を新規作成した。
- `docs/index.md` に仕様書と構成図を追記した。

## ゲーム仕様

- 全5ROUND制のタイムアタックとした。
- ROUND1 はゲート間隔を広くして、飛行操作に慣れるためのステージにした。
- ROUND が進むごとにゲート間隔を詰め、左右上下の揺さぶりを強くする。
- ROUND5 完走で FINISH。
- 地面激突または DAMAGE 100% で CRASH / GAME OVER。
- ROUND1 でクラッシュした場合は記録なし。
- ROUND2 以降でクラッシュした場合は、前ROUNDまでの到達記録をランキング対象にする。

## 操作

- スマホはプニコン操作を基本にした。
- スマホでは傾き操作も選択できるようにした。
- 傾き操作は感度を落とし、上下操作中に左右が暴れにくいよう、前後傾き時はロール入力を減衰する。
- PC は矢印キー / WASD と Space BOOST に対応した。
- 飛行機操作として、上入力は機首下げ、下入力は機首上げに統一した。

## 表示・UI

- Canvas は `375 x 500` の内部座標系で描画する。
- スマホでブラウザUIにプニコンが被らないよう、プニコンと BOOST ボタンは Canvas 内に配置した。
- 画面全体は `100dvh` 基準で中央寄せにした。
- HTML上部メーターは非表示にし、飛行中の計器は Canvas 内に描画する方式へ寄せた。
- 方角メーターを上部中央に表示した。
- 次ゲート誘導矢印は方角メーターと重ならないよう、少し下に配置した。
- スピードメーターは左上に丸型針メーターとして配置した。
- 高度計は右側に縦テープ式で表示した。
- 次ゲート方向がわかりにくかったため、大きな点滅矢印を表示した。
- 通過済みゲートは黄色表示にした。

## ランキング

- サーバ側に `airrace_scores.json` を追加し、ランキングを永続化する方式にした。
- `/api/airrace/scores` を追加した。
- 既存 `ScoreBoard` が「大きい score ほど上位」なので、ROUND とタイムを整数 score に符号化して保存する方式にした。

## 景観・演出

- ワイヤーフレーム風の地平線、ゲート、パイロンを描画した。
- 旋回時は地平線、地面、ゲート、パイロンを同じロール角で傾けるようにした。
- コース周辺に追加パイロン、木、草を配置し、飛行している密度感を増やした。
- 通常飛行音、BOOST音、ゲート通過音、パイロン接触音、クラッシュ音を WebAudio で実装した。
- FINISH / CRASH / GAME OVER 後は音を停止するようにした。

## 2026-04-22 17:41:07 JST - ベクター・エアレース: ゴースト履歴サーバ永続化

### 背景
- ローカル `localStorage` 保存のゴーストを試したところ、ゴーストが最後の12番ゲート付近に貼り付く挙動が出た。
- 端末ごとのローカル保存では、友人や別端末のプレイ履歴を共有できないため、サーバ側JSON永続化に切り替えることにした。

### 実装
- `app/src/main.rs` に `AirraceGhostStore` / `AirraceGhost` を追加した。
- `airrace_ghosts.json` をサーバ側の永続JSONとして読み書きするようにした。
- `/api/airrace/ghosts` を追加した。
- `GET /api/airrace/ghosts` は保存済みゴースト一覧を返す。
- `GET /api/airrace/ghosts?round=N` は対象ROUNDのゴーストだけを返す。
- `POST /api/airrace/ghosts` は1件の飛行履歴を保存する。
- 保存件数は最新100件までに制限した。
- 1履歴あたりのサンプル数は最大1200件に制限した。
- `app/src/airrace.html` は `localStorage` の `airrace_ghosts_v1` 依存をやめ、サーバAPIから `window.airraceGhosts` に読み込むよう変更した。
- ROUND CLEAR / FINISH 時に飛行履歴をサーバへPOSTするよう変更した。
- ゴースト再生は同一ROUNDの履歴を選択し、サンプル間を線形補間して表示する。
- 保存サンプル終端に達したゴーストは描画しないようにし、12番ゲートへ貼り付く見え方を避けた。

### 確認
- `cargo build` 成功。
- `docker compose restart` で開発サーバを再起動。
- `GET /api/airrace/ghosts` が `{"ghosts":[]}` を返すことを確認。
- `POST /api/airrace/ghosts` の疎通確認後、テスト用 `TEST` ゴーストを削除し、コンテナ内 `/workspace/app/airrace_ghosts.json` も空配列に戻した。
- `/airrace` のHTMLに `/api/airrace/ghosts` 呼び出しと `drawRival` の終端非表示処理が反映されていることを確認。

### 注意
- 実機で1回ROUND CLEARすると、以降同一ROUNDにサーバ保存ゴーストが表示される。
- 現状はランダムに1件選ぶ仕様。将来的にベストタイム優先や直近プレイ優先へ変更可能。
