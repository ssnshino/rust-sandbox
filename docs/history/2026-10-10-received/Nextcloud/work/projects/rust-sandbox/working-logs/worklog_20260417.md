## 作業内容

### Phase 3: マルチプレイ（〜4人）— PR #8, #9

**アーキテクチャ全面刷新**（`1接続=1ゲーム` → `Room/FloorInstance/PlayerSlot`）

- `PlayerSlot`: session_id / player / profile / inventory / kills / tx チャンネル
- `FloorInstance`: grid / aliens / holes / items / chests + `Vec<PlayerSlot>`
- `Room`: `HashMap<floor_num, Arc<Mutex<FloorInstance>>>` + 共有 ScoreBoard
- tokio tick ループをフロアインスタンスごとに独立起動
- `unbounded_channel` で tick→WebSocket へ非同期送信
- `to_json_for(pi)` で自分視点 + `others` 配列（他プレイヤー位置・名前・HP）
- フロア遷移時: PlayerSlot を旧フロアから取り出し → ボーナス加算 → 新フロアへ追加
- 切断: `remove_player(session_id)` のみ。ゲーム継続
- 途中参加: フロア1から開始
- PR #9 で最大4人キャップを追加（満員時はタイトル画面で待機）

### Phase 5: 聖なる床板と B ボタン — PR #10

- 各プレイヤー開始時に聖なる床板4枚所持
- `B` ボタンで足元に設置（エイリアン侵入不可の安全地帯）
- 足元の床板を `B` で回収可能（奪取も可）
- UI を `A / B / MENU` 3ボタンに整理
- BOX パネルに床板所持数表示追加

### Phase 6: エイリアン徘徊ロジック改善 — PR #11

- 平常時: 左手法ベース自動徘徊
- 一定確率で右手法へ切り替わる個体差
- 近距離時のみ追尾モード、見失ったら探索 → 徘徊へ戻る
- 聖なる床板周辺で入口を探す自然な動き
- フロアバランス調整も同時実施

### Phase 7: 日本語 / 英語 UI 切替 — PR #12

- タイトル画面に `🇯🇵 Japanese / 🇬🇧 English` ボタン追加
- 選択言語を `localStorage` に保存、次回起動時引き継ぎ
- `I18N` 辞書を `dungeon.html` に持たせ、GM セリフ・フラッシュ文言・メニューも切替
- サーバー側イベントキーはそのまま、表示はフロント辞書で吸収

### Phase 8: BGM・プレイヤーアニメーション — PR #13

- BGM 追加
- プレイヤーキャラクターのアニメーション描画強化

**実装方法**: Phase 8 は Codex CLI で実装

### Phase 2: 2P対戦・各種改善 — PR #15 〜 個別コミット

- **2P マッチメイキング**: Pong と同様の `FightRoom` + `Notify` + チャンネル方式
- **3本勝負**: `'match_loop` + `'round_loop` の2重ループ、先に2本取った方が勝ち
- **WIN!! / LOSE... 表示**: マッチ終了後オーバーレイ、「タイトルへ」ボタン
- **ラウンド結果表示**: `●○` でラウンドスコア表示
- **対戦待ち表示**: タイトル画面の「2人対戦」ボタンに待機中バッジ（3秒ポーリング）
- **HP バー修正**: P2（後から入った人）が右に表示・緑で自分を表示
- **タイトル復帰バグ修正**: 2P終了後 `showTitle()` で強制的に 1P WS に再接続（サーバー側は WS を閉じないため `gameMode === '2p'` チェックが必要）
- **CPU AI 改善**: 前進一辺倒を解消（後退フェーズ・ガード・攻撃タイミング多様化）
- **体型別ヒットボックス** (Codex CLI): キャラクターの体型に合わせたヒット判定
- **近距離調整・CPU 防御チューン** (Codex CLI)
- **ダメージ時スコアフロート表示** (Codex CLI)

### 実装メモ

- 2P WS は `run_2p` が `state_tx` を保持し続けるため、ゲーム終了後もサーバー側で WS が切れない。`showTitle()` での `gameMode === '2p'` チェックで強制 `connect('1p')` が必須。
- `include_str!` で HTML を埋め込むため、HTML 変更後は `touch + cargo build` が必要。
