### Pong/Breakout/あやかダンジョン 統合コミット（`4b29fec`）

前日の Pong に加え、Breakout とあやかダンジョンを一気に追加した。

**Breakout の設計ポイント**

- 1 接続 = 1 ゲームインスタンスの独立設計（マルチプレイなし）
- ブロック配置 10×6=60 個、行上位ほど高得点（row 0: 60pt → row 5: 10pt）
- 入力制御は `dir`（キーボード速度移動）と `paddle_x`（マウス・タッチ直接指定）を排他的に使い分け
- モバイル遅延対策として「即送信 + クライアント予測描画」を採用：`pointermove` で即 WS 送信し、パドルはローカル値で描画してサーバー返信を待たない

**あやかダンジョンの設計ポイント**

- 平安京エイリアン風の「穴を掘ってエイリアンを閉じ込める」メカニクスを採用
- 迷路生成: 再帰バックトラッカー（DFS）でパーフェクト迷路を生成後、ブレイド処理（18% 確率で行き止まりを除去）でループを作る
- フロア別サイズ: 1F=17×17, 2F=23×23, 3F=29×29, 4F以降=41×41（序盤を狭く）
- エイリアン AI は BFS パスファインドで最短経路を追尾、視界内（BFS距離≤8）で怒り速度に切り替え
- 穴のステートマシン: Digging → Open → Trapped / Filling の遷移でエイリアン捕獲を管理
- ゲームサーバーは 150ms ティック（60fps は重いためダンジョンに合わせて緩めた）
- フォグオブウォー: クライアント側でマンハッタン距離4以内のセルを `visited` に蓄積し描画
- スマホ操作: 仮想スティック（ぷにこん）で4方向量子化入力

## 判断メモ

- Breakout でクライアント予測描画をパドルにのみ適用したのは、ボールはサーバー物理に従わせないと整合性が崩れるため（パドルだけが直感的に動けば十分）
- あやかダンジョンのティック間隔を 150ms にしたのは、60fps だとキャラの移動速度感がゲームデザインと合わなかったため
- 穴の全状態でプレイヤー通過を禁止したのは、Digging 中だけ通れるバグを踏んだため（Open だけ禁止では不十分）

### ダンジョン フロア遷移バグ修正（`239d0c7`）

ゴール時に新マップが即座に描画されてしまう問題を修正。

**原因**: `grid` メッセージ受信時に即 `grid=msg.grid` を適用していたため、
CLEAR! メッセージ表示中にすでに新マップが描画されていた。

**修正方針**: 描画を止めて黒塗りにし、メッセージが終わったタイミングで描画再開。

```
ゴール → gameActive=false + 黒塗り → CLEAR!（1400ms）
       → START!（1200ms）→ gameActive=true → 新マップ描画開始
```

最初はグリッドを遅延適用する方針で試みたが、`state` メッセージが届き続けることで
プレイヤー・エイリアン位置が新フロアのものになり、旧マップ上に表示される問題が残った。
描画ループ自体を止める方針に切り替えて解決。
