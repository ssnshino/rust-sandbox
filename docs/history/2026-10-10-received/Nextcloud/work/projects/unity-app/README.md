# unity-app

Unityで作るアプリ・ゲームを継続的に育てる親プロジェクト。

## 目的

- Unity WebGL / Windows / macOS / Linux / Steam 配布を見据えた作業を、rust-sandbox本体から独立して管理する
- Unityプロジェクト固有の仕様、ビルド、配布、作業ログ、検証メモを集約する
- 実装リポジトリと公開先が複数にまたがっても、ここを見れば現在地がわかる状態にする

## 子プロジェクト

| プロジェクト | 概要 | 運転席 |
|---|---|---|
| airrace-unity | AirRace Unity 3D 移植版 | `airrace-unity/` |

## 共通方針

- Unityプロジェクト本体は、内蔵SSD容量を圧迫しないよう外付けSSDを正とする
- 配布やWeb公開に関する資料は各子プロジェクトの `refs/` に置く
- 作業ログは時系列、日時タイムスタンプ付きで残す
