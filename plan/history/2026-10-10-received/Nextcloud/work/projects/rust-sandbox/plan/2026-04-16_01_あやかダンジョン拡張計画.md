# あやかダンジョン拡張計画

最終更新: 2026-04-17 JST

## 目的

あやかダンジョンを、1人用のミニゲームから
4人協力プレイ対応のローグライト寄りアクションへ段階的に拡張する。

今回の方針は、ネットワーク構造をいきなり壊さず、
1人用でも意味のある機能から順に積み上げることを優先する。

#### 決定済みルール

**個別管理（プレイヤーごと）**
- HP / EXP / レベル / スコア / インベントリ
- 位置（それぞれ自由に動く）

**共有（フロアインスタンスごと）**
- マップ（グリッド）
- エイリアン（誰が穴に落としても共有。誰が埋めてもOK）
- 床のアイテムドロップ（先にとった人のもの）
- 宝箱（先にとった人のもの）

**フロア進行ルール**
- 各フロアはそのフロアに最初に入ったプレイヤーが生成する
- 先にゴールしたプレイヤーは即座に次のフロアへ単独で進む
- 残ったプレイヤーも各自ゴールすれば次のフロアへ合流できる
- フロアが違うプレイヤーは別インスタンスで独立して動く
- 途中参加プレイヤーはフロア1からスタート
- 切断プレイヤーはフィールドから消えるだけ（ゲームは継続）
- 最大4人まで（満員時はタイトルで待機）

#### アーキテクチャ

```
Room（ルーム）
  └─ FloorInstance（フロアインスタンス、フロアごとに1つ）
       ├─ grid / aliens / items / chests（共有）
       └─ Vec<PlayerSlot>（接続中のプレイヤー、各自個別ステータス）
```

PR: #11 `feat(dungeon): tune alien behavior and floor balance`

## 技術メモ

### プロフィール設計

- 当面は未ログイン前提で `player_id = None` / `name = 入力名`
- 後で認証導入時は `player_id = Some(user_id)` を差し込む構造
- ハイスコアも同じプロフィール名を初期値として流用

### マルチ時の確定事項

| 項目 | 方針 |
|------|------|
| HP / EXP / スコア | 個別 |
| インベントリ | 個別 |
| マップ / エイリアン | フロア共有 |
| 宝箱 / ドロップ | 先取り（取った人のもの） |
| 切断 | 消えるだけ |
| 途中参加 | フロア1から |
| フロア進行 | 各自独立してゴールで次へ |
| 最大人数 | 4人（将来的に16人想定） |
