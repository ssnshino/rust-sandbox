# 宇宙トラック野郎仕様書

最終更新: 2026-04-18 08:50 JST

## 概要

- `rust-sandbox` 上で動く、縦スクロール型の宇宙配送アクションゲーム
- 主人公は宇宙のトラック乗り `シノヤマ`
- 配送先ステーションへのドッキング、小惑星回避、鉱石採取、高速便イベントを組み合わせたスコアアタック型
- 原作小説 `アステロイドベルトの片隅で` のスピンオフ的な位置づけで、宇宙物流の現場感と軽妙な掛け合いを両立する

## 世界観と演出方針

- 主人公は「宇宙船パイロット」ではなく「宇宙のトラック乗り」
- GM は銀髪メガネっ娘の案内役で、軽快に状況を伝える
- 全体のノリはコミカルだが、単なるギャグではなく「宇宙で荷物を運ぶ仕事もの」の空気を残す
- ステージクリア時だけ、主人公と GM の顔カットインを表示する

## 基本ループ

1. ステーションから打ち上げ
2. 慣性付きで上方向へ航行
3. 小惑星を避けつつ、必要なら鉱石を採取
4. 終盤で目的地エアロックへ精密ドッキング
5. クリア演出
6. 次ステージへ進行

### タイトル画面

- タイトル
- 名前入力
- スタートボタン
- ランキング上位5件
- 日本語 / 英語切替

### プレイ中画面

- canvas 外 HUD
  - `SCORE`
  - `LIFE`
  - `ROUND`
- canvas 内要素
  - 自機
  - 背景スクロール
  - 小惑星
  - 鉱石
  - 目的地ステーション
  - ブースター中継ステーション（対象ステージのみ）
  - 進行バー
- canvas 下
  - GM メッセージ

### クリア画面

- `DELIVERY COMPLETE! / 配達完了！`
- サブメッセージ
  - 通常時はスコア表示
  - ブースター便予告時はブースター案内文
- 左に GM 顔カットイン
- 右にシノヤマ顔カットイン
- `次のステーションへ！` ボタン
- 約10秒で自動進行

### ゲームオーバー画面

- GAME OVER
- スコア
- ランク表示
- ランキング上位5件
- リスタートボタン

## 操作

### PC

- `↑ / W`: 上スラスター
- `↓ / S`: 下スラスター
- `← / A`: 左移動
- `→ / D`: 右移動
- `Space / J`: マニピュレーター

### スマホ

- 左下: ぷにこん
- 右下: `MAG` ボタン
- タイトル画面ではタッチ操作 UI は出さない

## 自機仕様

- 常に上向きの宇宙トラック
- 慣性移動あり
- スラスター入力が無い間も少し流れる
- スラスター演出
  - 上入力: 下に黄炎
  - 下入力: 上に青白炎
  - 左右入力: 逆側に青白炎
- 効果音
  - メインエンジン: 連続音
  - サイドスラスター: `ぷしっ`

## ライフ

- 初期ライフは 3
- 小惑星接触でダメージ
- 無敵時間あり
- 0 でゲームオーバー

## スコア

- 基本配送成功で加点
- ドッキング精度で追加点
  - perfect / good / ok
- 金鉱石 / レアメタル採取で追加点
- ラップ終了時は残ライフボーナスあり

## 鉱石

### 種類

- 金鉱石
- レアメタル

### 仕様

- 画面上部から小さく流れてくる
- 小惑星より小さく、狙って採取しやすい
- `MAG` ボタンでマニピュレーターを伸ばし、先端が触れると取得
- 取得時に得点加算と効果音

## ドッキング

### 通常ドッキング

- 終盤に目的地ステーションのエアロックが出現
- `▼` マーカーの先端に近いほど高得点
- 横方向のズレが大きすぎるとドッキング不可

### 中継ブースタードッキング

- 毎ステージではなく、3ステージに1回だけ対象ステージで発生
- 発生タイミング
  - ひとつ前のクリアカットインで「次はブースター便」の予告
  - 次ステージの発進直後に中継ブースターが出現
- 中継ステーションでブースター接続に成功すると
  - ボーナス点
  - 自機にブースターポッド表示
  - 後半戦が高速スクロール化
