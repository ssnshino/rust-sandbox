# あやかファイティング 実装計画

作成: 2026-04-17 JST

## 概要

イーアルカンフー風の横スクロール1対1格闘ゲーム。
1人用（CPU戦ステージクリア）と2人対戦（WebSocket）に対応。

## 画面フロー

1. **スタート画面**
   - 日本語/英語切替（localStorage保存）
   - ハイスコア上位5件表示
   - 「1人プレイ」「2人対戦」ボタン
2. **ゲーム画面**
   - 上部: SCORE / HIGH / STAGE
   - HPゲージ: 左=プレイヤー（右へ減少）/ 右=CPU（左へ減少）
   - キャラクター: Canvasで描画
   - 下部: あやかGM実況テキスト
3. **ハイスコア入力**（スコアが5位以内なら）
4. **スタート画面へ戻る**

## 操作（Punicon）

| 入力 | 動作 |
|------|------|
| 左右スティック | 移動 |
| スティック上 | ジャンプ |
| スティック下 | しゃがむ |
| Aボタン | パンチ |
| Bボタン | キック |

しゃがみ中にA/B → しゃがみパンチ/キック
ジャンプ中にA/B → 飛びパンチ/キック

## ステージ・敵キャラ

| Stage | 名前 | 特徴 |
|-------|------|------|
| 1 | ヨワヨワくん | パンチのみ、低速、ランダムに攻撃 |
| 2 | キッカー | キック特化、リーチが長い |
| 3 | ジャンパー | ジャンプ攻撃多用、タイミング変化 |
| 4 | ガードマン | 頻繁にガード、カウンター狙い |
| 5 | ボス | 全技使用、速い、HP多め |

## スコア計算

- ヒット: +50pt
- ステージクリア: +500pt × ステージ番号
- 残りHP ボーナス: 残HP × 100pt

## あやかGM 実況トリガー

- ステージ開始 / 敵登場
- ヒット成功 / 食らった
- ジャンプ攻撃成功
- 残りHP 30%以下
- ステージクリア
- ゲームオーバー
- 2P対戦時の煽り

## 技術構成

- `app/src/fighting.rs`: サーバー側ゲームロジック（30fps tick = 33ms）
- `app/src/fighting.html`: クライアント（Canvas描画 + Punicon入力）
- `app/src/main.rs`: `/fighting` + `/ws/fighting` ルート追加
- スコア: `ScoreBoard`（既存）を流用、`fighting_scores.json`

### WebSocket メッセージ

**Client → Server**
```json
{ "type": "start", "profile": {"name": "...", "mode": "1p"} }
{ "type": "input", "left": bool, "right": bool, "up": bool, "down": bool, "punch": bool, "kick": bool }
{ "type": "submit", "name": "...", "score": 0 }
{ "type": "restart" }
```

**Server → Client**
```json
{ "type": "title", "scores": [...] }
{ "type": "state", "p1": {...}, "p2": {...}, "stage": 1, "score": 0, "event": "..." }
{ "type": "gameover", "score": 0, "qualifies": bool, "scores": [...] }
{ "type": "stage_clear", "stage": 1, "bonus": 500 }
```

### サーバーゲームステート

```rust
struct Fighter {
    x: f32, y: f32,       // 座標
    vx: f32, vy: f32,     // 速度
    hp: u8, max_hp: u8,
    state: FightState,    // Idle/Walk/Punch/Kick/Jump/Crouch/Hurt/Dead
    state_timer: u32,
    facing: i8,           // 1=右向き, -1=左向き
    invincible: u32,
}

enum FightState { Idle, WalkF, WalkB, Punch, Kick, JumpPunch, JumpKick,
                  CrouchPunch, CrouchKick, Crouch, Jump, Hurt, Dead }
```

### 1P CPU AI パターン（敵ごと）

- **ヨワヨワ**: 一定距離でランダムパンチ、たまに近づく
- **キッカー**: キック射程に入ったら即キック、リーチ維持
- **ジャンパー**: 一定確率でジャンプ攻撃、着地後追撃
- **ガードマン**: ガード状態維持、攻撃を受けたらカウンター
- **ボス**: フェーズ制（HP50%以下で速度・攻撃頻度UP）
